# 智御网络

面向网络安全教育的三维交互式攻防仿真平台。项目以本地确定性规则演示网络拓扑、访问策略、事件传播和防御效果，不连接真实网络，也不执行真实扫描或攻击。

> 本系统采用教学型抽象网络安全仿真模型，用于展示网络拓扑、安全策略和事件传播之间的关系，不等同于真实网络环境中的漏洞利用、恶意代码执行或网络风险预测。

## 技术栈

- Vue 3、TypeScript、Vite、Vue Router、Pinia
- Three.js：可交互三维网络场景与事件路径动画
- Element Plus：交互控件与表单
- ECharts：仿真指标、状态分布和方案对比
- localStorage：保存当前场景配置
- Vitest：核心仿真规则测试

## 三个实验

1. **终端失陷与横向传播**：从实验开始前已受影响的办公终端出发，观察办公主机间传播及当前 Office→Database 暴露策略对关键资产的影响；办公区直达应用服务器默认被边界规则阻断。可为终端启用防护、隔离节点或启用 Office→Database DENY，验证数据库保护与必要业务可达性。
2. **外部访问与防火墙拦截**：模拟外部 WEB 与 DATABASE 请求，比较公开服务允许访问与关键数据服务默认拒绝的结果。
3. **网络分区防御实验**：在办公区、服务器区和数据区的同一拓扑中调整区域规则，观察风险范围与合法业务路径。

## 仿真模型与策略规则

仿真引擎在 `src/engine/` 中独立运行。`topologyEngine` 是路径查询的唯一实现；节点主机不能作为中继路由节点。目标服务由到达目标边界的连接服务标签校验，区域间访问再由安全规则决定。匹配范围越具体的规则优先；具体程度相同的规则中 `DENY` 优先；仍同级时按规则列表顺序。`service = ANY` 匹配所有服务。没有匹配规则时，存在可用服务路径即默认 `ALLOW`。

相同场景、初始状态和防御配置会生成相同的事件、快照和指标。每个事件携带引擎计算出的实际节点/连接路径、服务、策略命中与原因，Three.js 直接按该路径播放，不会另行搜索动画路线。时间线按事件索引显示 `T0`、`T1` 等步骤，并可恢复每一步的节点状态快照。

终端防护是教学抽象参数：启用后，后续传播事件无法使受保护的 Workstation 或 Server 进入受影响状态；它不回溯改变 seed 初始条件。隔离节点不能参与后续通信，可能降低业务可达率。

业务可达性根据场景配置的 `businessPaths` 逐条检查拓扑、服务、隔离和策略，显示可达路径数量与比例。该比例只表示当前实验预设业务路径可达情况，不代表真实企业 SLA。A/B 对照分别运行两次仿真：方案 A 恢复内置场景的安全策略，方案 B 使用实验室当前配置；两次共用同一拓扑、初始状态和 seed 事件。

## 安全挑战

主实验内置“保护 Customer Database”挑战。需要保护数据库，同时保留 Office → Public Web Server / WEB 与 Application Server → Customer Database / DATABASE 两条必要业务路径。挑战按钮会对当前配置重新运行仿真，并按实际关键资产状态及业务路径结果判定通过或失败；只封锁所有业务不能通过。

## 使用方式

- 首页进入三维实验室，选择任一实验并启动仿真。
- 使用开始、暂停、继续、单步、运行到结束和速度控制播放事件；点击事件日志或时间线可回放对应快照。
- 点击时间线事件可恢复其状态快照并定位对应节点；点击三维节点可查看和调整属性。
- 在安全策略面板配置来源区域、目标区域、服务和动作，新增、启用、禁用或删除规则；策略修改后需重新运行验证。
- 节点详情可修改名称、区域、关键资产属性，切换防护或隔离；设备面板可启用/禁用网络连接。拖动节点会自动保存在浏览器 localStorage。
- 可恢复内置默认配置、导入和导出场景 JSON。
- 在防御方案对比页调整方案 B 策略；A/B 使用同一个场景与初始事件。
- 实验分析页根据最近一次仿真或 A/B 对照生成指标、图表和规则化总结。

## 安全边界

本项目仅用于教学演示。所有攻击、传播和访问事件均为本地抽象模型，未实现真实网络扫描、漏洞利用、恶意代码、网络流量或后端服务。
