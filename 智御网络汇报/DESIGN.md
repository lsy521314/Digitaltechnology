# DESIGN.md — 智御网络参赛汇报

## 0. 设计宪法

- **画布**：1280 × 720 px，16:9。
- **页数**：35 页 = 22 页主线 + 13 页场景与功能图集附录（P.22–34）。附录沿用同一母版，信息密度更高。
- **视觉基调**：深空科技 / 克制 / 工程感 / 可读优先。深色不是“黑客滤镜”，而是让真实产品的青绿色状态色成为唯一亮点。
- **一句话规则**：每页只有一个视觉主角；数字大于形容词，路径大于图标，真实界面大于虚构插画。

## 1. 母版与安全区（A / B / C 三区）

| 区域 | 垂直位置 | 高度 | 内容规则 |
| :--- | :--- | :--- | :--- |
| **A · 标题块** | 40–120 px | 80 px | 左：kicker（11px mono，cyan）+ 页标题（30–34px bold）；右：可选页内说明（11px，muted） |
| **B · 内容区** | 132–656 px | 524 px | 所有正文、图表、图片、卡片；禁止越界 |
| **C · 页脚条** | 664–700 px | 36 px | 上方 1px 分隔线；左侧项目名（10.5px mono），右侧页码 `NN / 22`（10.5px mono） |

- 左右安全边距：**56 px**；内容宽 **1168 px**。
- 页标题基线固定在 top 62；kicker 固定在 top 38。
- 封面、章节扉页、结束页使用自定义版式，可省略 C 区；其余页面严格复用 A/B/C。
- 背景网格：64px 间距，`rgba(242,247,248,0.022)`；右上角径向青光是唯一背景光效。

## 2. 色彩系统（4 个 hex + 透明度派生）

| 角色 | Hex | 面积占比 | 用法 |
| :--- | :--- | :--- | :--- |
| **主色 · 深空底** | `#07111B` | 55–70% | 页面背景、封面压暗、图片蒙版 |
| **强调色 · 青** | `#6BC8D1` | ≤ 10%（Hero ≤ 15%） | 关键数字、路径线、通过状态、CTA、kicker、选中态 |
| **风险色 · 珊瑚** | `#E78172` | ≤ 6% | 仅用于“阻断 / 风险 / 失败 / 关键目标可达”，不做装饰 |
| **文本色 · 雾白** | `#F2F7F8` | 剩余 | 标题、正文；通过透明度形成层级 |

派生规则（不新增 hex）：

- 卡片底：`rgba(242,247,248,0.035)`；卡片描边：`rgba(107,200,209,0.16)`。
- 次级文字：`rgba(242,247,248,0.66)`；弱文字：`rgba(242,247,248,0.42)`。
- 青色半透明：`rgba(107,200,209,0.10–0.22)`；珊瑚半透明：`rgba(231,129,114,0.10–0.18)`。
- 图片内颜色不受此表限制（产品截图属于素材）。

**色彩节奏**：Hero 页强调色 12–15%；Supporting 页 ≤ 5%；章节扉页只用青色细线与巨字透明度，不出现珊瑚色。第 13、14 页允许珊瑚色集中于“阻断/风险”焦点，其余页面不得连续出现大面积珊瑚。

## 3. 字体系统

| 层级 | 字体 | 字号 | 字重 | 行高 / 字距 | 用途 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 封面主标题 | Microsoft YaHei | 82 px | 700 | 1.05 / 2px | 仅封面 |
| 章节巨字 | Consolas | 200 px | 700 | 1.0 / -6px | 章节扉页背景数字，opacity 0.07 |
| 章节标题 | Microsoft YaHei | 54 px | 700 | 1.2 / 1px | 章节扉页 |
| 页面标题 | Microsoft YaHei | 32 px | 700 | 1.25 / 0.5px | A 区；长标题 30px |
| 导语 | Microsoft YaHei | 18 px | 400 | 1.7 | 标题下 1–2 行判断 |
| 正文 | Microsoft YaHei | 14 px | 400 | 1.75 | 卡片、段落 |
| 小字 / 注释 | Microsoft YaHei | 11.5 px | 400 | 1.65 | 图注、补充说明 |
| 数据标签 | Consolas | 11 px | 500 | 1.4 / 1.5px | 编号、模式、页码、英文标签 |
| 巨型数字 | Consolas | 88–160 px | 700 | 1.0 / -4px | 视觉锚点 |
| 关键数字 | Consolas | 44–64 px | 700 | 1.0 | 指标卡 |

- 中文只用 **Microsoft YaHei**；数字 / 英文标签只用 **Consolas**。全篇不超过两套字体家族。
- 正文行长控制在 30–38 个汉字；超过 3 行必须拆段或改为列表。
- 禁止使用斜体中文；强调用颜色、字重或左侧 2px 青线。

## 4. 间距与容器

- 基础间距单位：8 px；常用 gap：16 / 20 / 24 / 32 / 40。
- 卡片圆角：10 px；小标签圆角：4 px；圆形节点：50%。
- 卡片内边距：20–24 px；卡片之间 gap：16–20 px。
- 卡片填充率 ≥ 85%：卡片底部标签/数字用 `marginTop: 'auto'` 或 `justifyContent: 'space-between'` 钉底。
- 留白上限：常规页 ≤ 35%；Hero 页 30–40%；章节扉页 45%。
- 视觉锚点：每页至少 1 个 ≥ 40% B 区面积的图，或 ≥ 64px 数字，或 ≥ 44px 的巨型判断。

## 5. 渐变与半透明

- 封面 / 结束页底图蒙版：`linear-gradient(90deg, #07111B 0%, rgba(7,17,27,0.94) 34%, rgba(7,17,27,0.48) 64%, rgba(7,17,27,0.82) 100%)`。
- 卡片：`linear-gradient(145deg, rgba(242,247,248,0.055) 0%, rgba(242,247,248,0.022) 100%)`。
- 青色光晕：`radial-gradient(circle, rgba(107,200,209,0.16) 0%, rgba(107,200,209,0) 70%)`，只出现在 Hero 页或关键图背后。
- 图片覆盖说明条：`rgba(7,17,27,0.78)` + 1px 上边框 `rgba(107,200,209,0.18)`。
- 禁止大面积霓虹渐变、彩虹色、玻璃拟态叠三层。

## 8. 版式规则

- 相邻页不得使用同一版式；章节扉页统一使用“巨字 + 左标题”，视为同一母版，允许连续章节页结构一致。
- `N卡片横排` 全篇仅第 7 页使用一次（3×2 模块矩阵）。
- 非对称版式 ≥ 70%；`左大图+右侧文字` 与 `非对称双栏` 合计不超过 50%。
- 每页必须有且仅有一个主角：图 / 巨字 / 数字 / 判断句。其余元素降一级。
- 标题块右侧不得塞装饰小图；页内说明只允许一行 mono 小字。
- 页脚位置、页码格式全篇一致；封面、章节页、结束页可省略。

## 9. 页面细节约束

- **第 4 页**：三个困境用 01/02/03 大编号，不用图标；右侧断点图用“配置文本 → ? → 业务结果”三段，问号 64px。
- **第 10 页**：架构图三栏，左右两栏窄、中间两引擎上下叠；虚线箭头必须标注“仅前置条件”。
- **第 12 页**：规则栈真实使用 `internal-fw` 的 10/20/25/30 四条规则；第 1 条命中用青色高亮，第 30 条 DENY 用珊瑚描边但不抢焦点。
- **第 13 页**：四个状态节点用横向链条；T3 的 `DATA_ACCESS` 用珊瑚标签“可被数据访问控制阻断”；底部左侧给“8 / 160”边界数字。
- **第 17 页**：7 行场景，模式用 6px 圆点 + mono 标签；ATTACK_STATE 用珊瑚点，TEACHING_PROPAGATION 用青点；难度/时长右对齐。
- **第 19 页**：左侧巨字判断 40px；右侧 4 条边界 + 底部 6 个文献缩写；文献只写机构 + 编号，不写长标题。
