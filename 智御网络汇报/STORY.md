# STORY.md — 智御网络参赛汇报

## ① 用户意图对齐

- **目标受众**：全国大学生数字媒体科技作品及创意竞赛评委。评委同时关注创意表达、技术完成度、交互体验与作品价值，未必是网络安全专业背景。
- **核心目标**：让评委相信这不是一段“攻击动画”，而是一套把网络语义、攻击状态与策略验证真正跑通的交互系统；看完记住一句话——**通信可达 ≠ 状态改变**；并认可作品在教学中“可观察、可干预、可解释、可复现”的价值。
- **PPT 长度**：35 页（22 页主线 + 13 页场景与功能图集附录）。Hero 页 6 页（21%），章节扉页 5 页，其余为信息承载页。
- **视觉调性**：深空科技、克制、工程感、可读优先；用产品真实界面做视觉锚点，不用虚构的攻击画面。
- **内容边界**：
  - 必讲：教学痛点、产品定位、完整功能面、双引擎机制、三维交互、策略判定、攻击状态链、A/B 与复现、7 个场景、教学闭环、工程质量、模型边界、创新与价值。
  - 不讲：真实漏洞利用细节、任何“可预测真实风险”的暗示、未实现的功能、虚构的团队/学校信息。
  - 禁碰：把教学抽象包装成真实攻击能力；用“黑客大片”式视觉替代机制说明。

## 数据与判断落点

- **111 个测试全部通过** → 不是“能跑就行”的原型，而是可回归的工程系统。
- **7 个场景 / 2 种仿真模式** → 覆盖从入门到挑战，但共享同一套通信与策略判定，不是七套脚本。
- **10,121 行源码 / 0 后端** → 纯前端交付，课堂分发零部署；同时意味着模型必须自洽、可测试。
- **深度 8 / 160 状态** → 搜索有明确边界；达到边界会标注“未完整”，不把“没搜到”伪装成“安全”。
- **数据目标 可达 → 受保护，业务 100% → 100%** → 好的安全策略不是“一刀切断开”，而是在保护关键资产的同时保持必要业务。
- **4 类教学行为 / 3 种结果** → 每次状态变化都有前置条件与结果类型；失败也可解释。

## 叙事主线

1. **问题**：安全策略教学“看不见、不敢动、难验证”。
2. **作品**：把企业网络做成浏览器里的三维沙盘，改策略、跑仿真、看结果。
3. **机制**：通信引擎与攻击状态引擎分离；通信可达只是前置条件。
4. **验证**：7 个场景 + A/B + 指纹 + 分享链接；从学到考形成闭环。
5. **价值**：可观察、可干预、可解释、可复现；边界清楚，所以可信。
